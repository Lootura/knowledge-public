About

A public atlas of entities that change over time

Lootura Entity Atlas turns source-backed ingest into public entity pages: companies, places, people, products and topics with timelines that can be searched, indexed and followed.

The site is intentionally entity-first. A news item is useful because it may change what we know about an entity. The public product is not a feed of articles; it is a set of durable entity URLs with summaries, timelines, evidence and related context.

The home page is a search surface. The directory lets people and crawlers browse entities alphabetically. Activity shows the latest ingest outcome in plain language: which entities were updated and which ones became visible.

Behind the HTML there is JSON. The entity files are the canonical product layer and are designed to be reused later by an API, an MCP server, a ChatGPT app or other AI agents.

Input

Source-backed ingest from selected public source items.

Model

Knowledge changes update entities instead of rewriting news headlines.

Output

Searchable, indexable entity URLs with evidence behind them.

Search

Start with the entity name and move directly into its public page.

Browse

Use the directory like a dictionary when the exact entity is not obvious.

Follow

Use activity and timelines to understand what changed since the last ingest.

Lootura Entity Atlas is a simple public index of entities updated by validated events.
